# E-Commerce Sales Analytics Dashboard

## Project Description
This project is a cloud-based analytics dashboard that visualizes Amazon e-commerce sales data using Supabase and Chart.js. The dashboard displays key performance indicators, sales charts, order status distribution, and sales trends.

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
- Supabase
- Python Pandas
- Vercel

## Features
- Total Orders KPI
- Total Revenue KPI
- Average Sales KPI
- Sales by Category Bar Chart
- Order Status Pie Chart
- Sales Trend Line Chart
- Category Filter
- Responsive Layout

## How to Run Locally
1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select `Open with Live Server`.
6. The dashboard will open in the browser.

## Dataset
The dataset used is an Amazon Sale Report dataset from Kaggle. It was cleaned and reduced to 999 rows to meet the project requirement.

## Database
The cleaned dataset was uploaded to Supabase under the table name `amazon_sales`.

## AI Integration
The dashboard includes an AI-powered insight generator using a free AI API to generate business insights from the dataset.
